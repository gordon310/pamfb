## 分歧点与待确认事项

- **投资数据可得性差异较大**：夏国跃只能提供「餐饮整体投资总额」，章生「可估算」，何强「无法提供 / 暂不录入」。平台需支持 **按餐厅分项 / 整体 / 估算 / 暂缺** 四档容错。
- **投资录入方式**：夏、章希望「按投资构成分项填写」，何强「暂不录入」。
- **年费采购路径**：夏「可接受直接采购」、章「需内部审批」、何「应由集团统一采购」。需同时支持 **单店年费** 与 **集团打包**。
- **竞争对手范围确定**：夏「按同档次同业态」、何「按地理位置同商圈」、章「酒店自行指定」。建议提供三种规则并允许酒店自选。
- **社会餐饮是否付费**：夏、何主张「纳入订阅」，章主张「是（顾问报告）」。
- **报告频率**：夏「实时+月度」、何「实时+月度+年度+事件触发」、章「月度」。
- **是否扣除经营成本**：夏、章「两者都要（含净收益口径）」、何「暂不确定」。
- **是否参与匿名对标**：夏、章倾向「集团可见」，何「可参与匿名对标」。

## 开发建议（第一阶段 MVP）

综合 Q50「第一阶段最重要 5 项」提名及其他题目的需求反馈，建议排期如下。MVP 提名与一般需求支持分别统计；何强原答卷对应题号为 Q52，已归一化为 Q50。

1. **餐饮设施基础数据 + 经营数据采集**（分餐厅 / 分宴会厅 / 分餐段）——3/3 提名「设施基础数据」、2/3 提名「经营数据」。
2. **竞对数据对标**——3/3 提名，且为 3/3 核心痛点。
3. **餐饮投资数据录入**（支持分项 / 整体 / 估算 / 暂缺）——MVP 提名 1/3（夏国跃）；另有 2/3 希望按投资构成分项填写（Q20）。
4. **投资回报分析**（ROI、年化回报率、坪效投资比、单座投资额、收入投资比，按年，**不含折旧**）——MVP 提名 1/3（夏国跃）；一般指标需求中，ROI 为 3/3（Q22）。
5. **数据脱敏上传 + 权限与匿名对标**——MVP 提名 1/3（章生）；数据安全顾虑为 1/3（Q51），要求脱敏上传为 3/3（Q43）。
6. **在线看板（实时）+ PDF 报告**——一般报告需求：3/3 期望在线看板与 PDF（Q46）。
7. **宴会独立分析 / 社会餐饮对标**——MVP 各 1/3 提名（何强）；一般需求中，宴会独立分析为 3/3（Q31），社会餐饮对标报告为 3/3（Q3）。
